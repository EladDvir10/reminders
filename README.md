# אפליקציית תזכורות לאנדרואיד

1. פתח חשבון חינמי ב־github.com (אם אין).
2. צור Repository חדש (New repository), קרא לו reminders, השאר Public או Private.
3. לחץ "uploading an existing file", גרור פנימה את כל תוכן התיקייה הזאת (כולל התיקייה .github) ולחץ Commit changes.
4. עבור ללשונית Actions, המתן 5-10 דקות עד שהריצה "Build Android APK" מסתיימת בסימן ירוק.
5. היכנס לריצה, למטה תחת Artifacts הורד את reminders-apk. פתח את ה־ZIP והתקן את app-debug.apk בטלפון.
